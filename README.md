## Instalación y uso:
```bash
git clone https://github.com/HolaMundoDev/aprende_js_html_css_node.git
cd aprende_js_html_css_node
cd carpeta_de_la_seccion
npm i
```

Verás un archivo example.env. Puedes copiar las variables de entorno que hemos definido para que el proyecto funcione, y en un nuevo archivo .env pegar estas variables y sustituir con el valor solicitado.

### Para ejecutar el servidor:
```bash
node api.js
```

Y en el navegador, entra a la dirección http://localhost:3000/
